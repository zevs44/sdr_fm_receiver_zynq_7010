# Периферия платы

Что несёт контрольная плата Antminer S9 (Zynq-7010), что использует OpenWrt
и как добраться до остального. Источники: схема платы (номера листов указаны ниже),
дерево устройства платы в этом репозитории и файл ограничений FPGA.

## Что распаяно

| Узел | На плате | Следствие |
|---|---|---|
| Колодки J6, J7, J8 | есть | сюда выведены внешний I2S и антенна |
| Колодки J1–J5, J9 | нет | у выводов J2 (ΔΣ-ЦАП), J4 (FM-аналог) и входа J9 (внешний I2S) нет разъёма |
| Разъёмы FAN5, FAN6 | есть | можно подключить два вентилятора |
| Разъёмы FAN1–FAN4 | нет | в схеме помечены `FAN HEADER_NC` |
| Кнопки S1, S2 | есть | сброс и сообщение адреса |
| Индикаторы PS | три: MIO15, MIO37, MIO38 | управляются `gpio-leds` |
| Индикаторы PL | четыре: M17, M19, L19, F16 | управляются битстримом |
| Зуммер BZ1 | нет | есть только площадка и ключевой транзистор |

## Индикаторы PS

Три индикатора относятся к PS и видны в `/sys/class/leds`:

| Имя в sysfs | Пин | По умолчанию |
|---|---|---|
| `s9:red:usr` | MIO37 | выключен |
| `s9:green:usr` | MIO38 | горит после загрузки (`default-on`) |
| `s9:red:inner` | MIO15 | выключен |

Нужны пакет `kmod-leds-gpio`, который входит в образ, и узлы в дереве устройства.
Управление из консоли:

```sh
ls /sys/class/leds
echo 1 > /sys/class/leds/s9:green:usr/brightness
```

Те же индикаторы доступны в LuCI: **System → LED Configuration**. Значения
по умолчанию записывает один раз `/etc/uci-defaults/98_antminer_leds`.

## Кнопки

| Кнопка | Пин | Поведение |
|---|---|---|
| `reset` (S1) | MIO47 | короткое нажатие — перезагрузка; удержание 5 с и более — сброс к заводским и вход в failsafe |
| `ip_get` (S2) | MIO51 | короткое нажатие — повторная аренда DHCP на `lan`, адрес пишется в журнал |

События раздаёт `gpio-button-hotplug`; имя берётся из свойства `label` в дереве
устройства, обработчик — `/etc/rc.button/<label>`. Проверка:

```sh
logread -f | grep -i ip_get
```

## Зуммер

`BZ1` — площадка на листе 4 схемы, рядом с ключевыми транзисторами Q2/Q3 и кнопкой S2.
Две площадки:

| Контакт | Цепь | Значение |
|---|---|---|
| 1 | через диод D4 (`1N4148`) от шины 3,3 В | плюс излучателя |
| 2 | коллектор Q1 (`MMBT3904`) | минус, ключ на землю |

База Q1 подключена через R39 (1 кОм) к MIO39; параллельно зуммеру стоит C20 (0,1 мкФ).
Ставить нужно **активный** зуммер на 3,3 В с двумя выводами. Полярность проверяется
мультиметром: плюсовая площадка соединена с катодом D4.

Пересборка не нужна: узел уже объявлен в дереве устройства как индикатор.

```sh
echo 1 > /sys/class/leds/s9:buzzer/brightness
sleep 1
echo 0 > /sys/class/leds/s9:buzzer/brightness
```

Пассивному излучателю нужна прямоугольная волна: понадобится PWM в битстриме
и драйвер `pwm-beeper`.

## XADC

Внутренний АЦП даёт температуру кристалла. Узел включён в дереве устройства платы,
драйвер встроен в образ.

```sh
cat /sys/bus/iio/devices/iio:device0/name        # xadc
cat /sys/bus/iio/devices/iio:device0/in_temp0_raw
cat /sys/bus/iio/devices/iio:device0/in_temp0_offset
cat /sys/bus/iio/devices/iio:device0/in_temp0_scale
```

Температура в миллиградусах: `(raw + offset) * scale`.

## Вентиляторы

Управление вентиляторами живёт в FPGA: `FAN_PWM` на BANK35_L14P, `FAN_SPEED1…6`
на BANK35_L15P, L15N, L16P, L16N, L17P и L17N (схема, лист 6). Один ШИМ-выход общий
для всех каналов, у каждого канала свой вход тахометра. Текущий битстрим их
не использует, интерфейса в Linux нет: чтобы подключить вентиляторы, нужны модуль PWM
и счётчики в дизайне.

## Определение карты и защита от записи

У слота microSD оба переключателя разведены на PS: определение карты на MIO46
(`CD_SW`), защита от записи на MIO50 (`CD_WP`). По умолчанию они не используются.

Патч `target_patches_optional/0350_zynq_sd_card_detect.patch` добавляет `cd-gpios`
и `wp-gpios` в узел `sdhci0`. Перед включением нужно измерить полярность: при обратной
ядра решит, что карты нет, и плата не загрузится с той же карты, с которой стартовала.
Рецепт замера — в README каталога патчей.

## Замечания и ограничения

- Разъёма USB на плате нет, хотя `usb0` в дереве устройства остаётся включённым
  из поддержки платы в исходном репозитории.
- Битстрим по-прежнему формирует сигналы J2 и J4, но колодки не распаяны: сигналам
  некуда идти.
- Четыре индикатора PL показывают состояние приёма из битстрима (захват стерео,
  найдена станция, синхронизация RDS, рабочий такт звука); Linux ими не управляет.
- Всё перечисленное сверено со схемой и деревом устройства; зуммер и переключатели
  карты на железе ещё не измерялись.
