# Битстрим FPGA

Здесь лежит `system.bit.gz` — сжатый битстрим, который U-Boot загружает в PL командой
`fpga loadb` до старта ядра.

## Почему файла может не быть

Битстрим **нельзя собрать в GitHub Actions**: лицензия Vivado Basic привязана к конкретной
машине (node-locked) и не переносится на раннер, а установка занимает ~30 ГБ.
Поэтому файл собирается локально и кладётся сюда вручную.

Если файла нет, `scripts/apply.sh` предупредит, а образ соберётся **без PL**: система
загрузится, но радио, I2S и ΔΣ-ЦАП работать не будут.

## Как получить файл

1. Vivado 2026.1 + Basic-лицензия.
2. Правка проекта и сборка — скриптом из проекта `zynq-pcm5102`:
   `02_tools/01_rebuild_i2s_out.tcl` (см. `05_vivado_rebuild_guide.html`).
3. Сжать без метаданных времени, иначе файл меняется при каждой сборке:

```bash
gzip -9 -n -c design_1_wrapper.bit > system.bit.gz
```

4. Положить результат сюда и закоммитить.

## Что должно получиться

| Параметр | Значение |
|---|---|
| Размер `.bit` | ~2 МБ |
| Размер `.gz` | ~360 КБ |
| Первые байты распакованного | `00 09 0f f0` |
| Имя дизайна внутри | `design_1_wrapper` |

Проверка:

```bash
gzip -dc system.bit.gz | head -c 16 | od -An -tx1
```
