# Битстрим FPGA

Здесь лежит `system.bit.gz` — сжатый битстрим, который U-Boot загружает в PL
командой `fpga loadb` до старта ядра. Сборка образа кладёт его в FAT-раздел.

## Что лежит сейчас

| Параметр | Значение |
|---|---|
| Источник | релиз `v1.0.0` (2026-08-16) репозитория [alexsys87/sdr_fm_receiver_zynq_7010](https://github.com/alexsys87/sdr_fm_receiver_zynq_7010), файл `openwrt-zynq-s9-antminer_s9-ext4-sdcard.img.xz`, FAT-раздел |
| Размер `.gz` | 360 709 байт |
| Размер после распаковки | 2 083 854 байта |
| SHA-256 | `7171a0347801109371d1d734294355ebd9382e49b776009305e96793284b8d7c` |
| Имя дизайна | `design_1_wrapper` |
| Магия | `00 09 0f f0` |

Это **штатный дизайн автора**: FM-приёмник, мультиплексор трёх источников,
дельта-сигма ЦАП на колодке J2, внешний вход I2S на J9, FM-передатчик на T16.
Внешнего **выхода** I2S в нём нет — см. [`docs/audio-path.md`](../docs/audio-path.md).

## Почему файл в репозитории

Битстрим нельзя собрать в GitHub Actions: лицензия Vivado Basic привязана к
конкретной машине (node-locked), а установка занимает ~30 Гб. Поэтому файл
собирается локально и хранится здесь — как любой другой артефакт, без которого
образ неработоспособен.

У исходного репозитория нет файла лицензии. Битстрим взят из опубликованного
автором образа для совместимости с его пакетами и будет заменён собственной
сборкой при первой возможности.

## Как заменить на свою сборку

1. Собрать битстрим в Vivado (см. [`docs/rebuild-bitstream.md`](../docs/rebuild-bitstream.md)).
2. Сжать без метаданных времени — иначе файл меняется при каждой сборке:

   ```bash
   gzip -9 -n -c design_1_wrapper.bit > system.bit.gz
   ```

3. Проверить результат (см. ниже) и обновить таблицу выше: источник, размер, SHA-256.
4. Закоммитить и записать изменение в `FORK_CHANGES.md`.

## Проверка

```bash
ls -l system.bit.gz                          # ~360 Кб
gzip -dc system.bit.gz | wc -c               # ~2 000 000 байт
gzip -dc system.bit.gz | head -c 4 | od -An -tx1   # 00 09 0f f0
sha256sum system.bit.gz                      # сверить с таблицей
```

## Если файла нет

`scripts/apply.sh` предупредит, а образ соберётся без PL: система загрузится, но
радио, I2S и ΔΣ-ЦАП работать не будут.
