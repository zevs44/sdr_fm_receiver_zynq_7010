# Необязательные патчи

Здесь лежат патчи, которые **не применяются** сборкой: `scripts/apply.sh` берёт
только `target_patches/*.patch`. Файл переносится в `target_patches/` после того,
как выполнена указанная ниже проверка на плате.

## `0350_zynq_sd_card_detect.patch`

Добавляет в узел `&sdhci0` строки:

```
	cd-gpios = <&gpio0 46 0x1>;
	wp-gpios = <&gpio0 50 0x1>;
```

Что даёт: определение карты (`cd-gpios`) и защиту от записи (`wp-gpios`) идут
от переключателей слота microSD: MIO46 `CD_SW` и MIO50 `CD_WP` (даташит, строки
248–249). Внешних проводов не нужно — переключатели уже внутри слота.

Почему не включено по умолчанию: если полярность окажется обратной, ядро решит,
что карты нет, и **плата не загрузится** — корень на этой же карте. Автор прошивки
эти линии не использует вовсе (`xlnx,has-wp = <0>`, `cd-gpios` нет), то есть
готового подтверждения нет.

### Проверка перед включением (2 минуты, без пересборки)

`devmem` пишет в SLCR и GPIO напрямую; после перезагрузки значения сбрасываются.

```sh
# 1. Настроить MIO46 и MIO50 как входы с подтяжкой (SLCR MIO_PIN_x: TRI_ENABLE, PULLUP)
devmem 0xF80007B8 32 0x00010001     # MIO_PIN_46
devmem 0xF80007C8 32 0x00010001     # MIO_PIN_50

# 2. Читать состояние банка 1 (GPIO_DATA_RO_1)
devmem 0xE000A044 32
```

Бит 14 регистра — MIO46 (карта), бит 18 — MIO50 (защита от записи).

- Вынуть и вставить карту: бит 14 должен менять значение. Если при вставленной
  карте он равен 0 — полярность `0x1` (активный низкий) верна.
- Перевести ползунок защиты в положение «lock»: бит 18 должен измениться.
- Если значения обратные — заменить `0x1` на `0x0` в обеих строках патча.

### Включение

```sh
git mv target_patches_optional/0350_zynq_sd_card_detect.patch target_patches/
git commit -m "Detect the SD card and its write protection"
```

После сборки проверить на плате: `dmesg | grep mmc`, `block info`, вставка
и извлечение карты на ходу, монтирование только для чтения при включённой защите.
