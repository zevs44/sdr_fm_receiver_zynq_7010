# Исключения именования

> Дата последнего обновления: 2026-11-28.

Реестр исключений именования этого репозитория (N-26 свода `ai-standards`). Каждая
запись `.namingignore` привязана к строке реестра; исключение без записи считается
дефектом (N-24). Причины и границы записей E1–E11 заданы в Каноне и здесь
не повторяются (N-45).

## Исключения проекта

Собственных исключений нет: все записи относятся к исключениям Канона, перечисленным
ниже. Бюджет — 0 из 8.
